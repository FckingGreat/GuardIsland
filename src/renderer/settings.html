Обзор

Клик по капсуле сверху раскрывает остров. Кнопка «Свернуть» возвращает маленькую капсулу. «Скрыть» убирает её полностью — вернуть из трея.

Пока охрана включена, обычное «Снять задачу» в диспетчере не сработает. Если процесс всё же убьют, Windows блокируется и Guard Island поднимается снова. Штатный выход — пароль запуска программ.

Лицо

Ваше лицо хранится только на этом ПК. Чужой в кадре — действие ниже.

Клавиша

Глобальная клавиша. В тесте — только сообщение на острове.

USB

Новая флешка, мышь или диск. Уже вставленные при старте не считаются.

Программы

Новый exe сразу ставится на паузу, пока не введёте пароль. Windows, WSL и Node не трогаем. В ослабленном режиме спрашиваем только сомнительные запуски (Загрузки, флешки, одиночные exe с рабочего стола) — без пачки окон пароля.

Лист без проверки

Эти программы и всё, что они сами запускают, пароль не спрашивают. Добавить можно из окна запроса.

Аномалии

Desktop, Documents, Downloads и Telegram: пачки файлов и несколько ChatExport сразу.

Связь

Скрытого бэкдора нет. Доступ через Tailscale на вашем аккаунте.

О приложении

  • Guard Island — охранный слой для вашего компьютера.
  • Выход из приложения — тот же пароль, что на запуск программ.
  • Пока охрана вкл, обычный End task процесс не снимает. Если убьют — приложение поднимается снова, без блокировки Windows.
  • Обновление установщиком не трогает пароли и настройки: они в профиле Windows, не в папке программы.
